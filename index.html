Detection Information

Bounding boxes show where the model believes objects are located. Confidence values indicate the model's prediction score. Results depend on lighting, camera quality, object size and distance.

This initial model supports common pretrained classes. It is not specifically trained to detect stones, gravel, tree trunks or every possible animal and vehicle. Those require additional training and testing.
